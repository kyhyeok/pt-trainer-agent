# frontend — 트레이너용 웹 화면 (Vite + React + Tailwind)

`@flue/react`의 `useFlueAgent`로 백엔드 에이전트 대화 하나를 실시간으로 따라간다. `@flue/react`·`@flue/sdk`는 백엔드의 `@flue/runtime`과 같은 버전(2.3.0)으로 고정한다.

## 구조

- `src/App.tsx` — 접속 화면(토큰·대화 이름 확인)과 채팅 전환. 토큰은 `lib/session.ts`로 sessionStorage에만 둔다.
- `src/Chat.tsx` — 메시지 목록, 도구 호출 줄, 초안 상자(복사될 글을 그대로 보여 주고 받는 사람 표시), 확정 요청 전송(20초 제한), 첨부 사진 표시(토큰을 붙여 백엔드에서만 받아 옴). 긴 대화에서 느려지지 않도록 메시지·글 묶음을 `memo`로 감싼다. 메시지마다 오류 경계(`MessageBoundary`)를 둬서 한 메시지의 렌더 예외가 화면 전체를 멈추지 않게 한다. 초안은 메시지의 글 묶음 배열을 그대로 넘겨 묶음마다 파싱한다.
- `src/Composer.tsx` — 입력창(사진 첨부·붙여 넣기·끌어다 놓기, 보내기). 입력할 때 메시지 목록이 다시 그려지지 않도록 상태를 따로 둔다. 보내는 동안은 입력을 잠그고(연타는 ref로 막음), 접수에 실패한 같은 내용을 다시 보낼 때는 같은 idempotencyKey를 쓴다.
- `src/ApprovalCard.tsx` — 확정 카드 표시.
- `src/lib/` — 순수 함수와 설정. `*.test.ts`가 단위 테스트다.
  - `approvals.ts` — 제안 도구 결과에서 카드 꺼내기, 신호(`signal.attributes`)에서 결정·결과 모으기, 카드 상태 계산
  - `drafts.ts` — 답변 메시지 전체에서 "회원에게 보낼 문장(초안)" 꺼내기. 답변을 마크다운 구조(mdast)로 파싱해, 백엔드와 약속한 표시 줄(`── 회원에게 보낼 문장(초안) ──`, `backend/AGENTS.md` 참고)이 문서 맨 바깥(문단 첫 줄·제목·식단 코드 블록)에 있을 때만 인정한다. 초안은 다음 문단 하나. 복사 글은 화면과 같은 파서로 만든다. 애매하면 꺼내지 않는다
  - `parts.ts` — 답변 파트를 화면 묶음으로 나누기(추론 조각에 끊긴 텍스트 잇기)
  - `markdown.ts` — 마크다운 설정(원시 HTML·이미지 차단, `~` 하나는 취소선 아님)
  - `image.ts` — 사진을 JPEG로 다시 만들기(긴 변 1600px), 크기·파일 이름 계산
  - `tools.ts` — 도구 호출 줄의 이름과 짧은 결과(카드로 못 그린 제안은 경고로 표시)
  - `conversation.ts` — 대화 id 규칙, 백엔드 주소 검사, 토큰을 붙여도 되는 주소 판정

## 규칙

- 토큰을 번들(`import.meta.env`)·localStorage·URL에 넣지 않는다. 토큰은 백엔드 주소로 가는 요청에만 붙인다(`isAgentResource`).
- 에이전트 답변은 신뢰하지 않는다. 원시 HTML을 그리지 않고, 마크다운 이미지는 불러오지 않는다. 트레이너가 쓴 글은 마크다운으로 해석하지 않는다.
- 확정 여부는 화면 상태가 아니라 대화 기록의 신호로 판단한다(새로 고쳐도 같게 보이도록). 한 제안에는 결정 요청을 한 번만 보낸다.
- 일정 판정은 화면에서 하지 않는다. 화면은 백엔드가 준 요약·경고·결과만 보여 준다.
- 로직을 바꾸면 `src/lib`의 테스트를 먼저 고친다.
